# WalkieTalkey desktop copy

Every Danish string the desktop screens show (onboarding, settings, history,
pill, dialogs). The strings live in `src/i18n/locales/da/translation.json`
under `wt` (English in `en`). JSON cannot hold comments, so the status is
kept here:

- **Appendix A**: the spec's copy, used verbatim (docs/SPEC.md, Appendix A).
- **TODO(copy)**: drafted by the implementer; needs the owner's approval
  before release (spec Appendix A, "Missing strings").

365 strings, 323 marked TODO(copy). Generated by
`bun scripts/walkietalkey/copy-list.ts`; `--check` fails when this file is
out of date.

Also for the owner:

- TODO(copy): macOS System Settings labels quoted in onboarding step 4
  ("Inputovervågning", "Tastatur", "Tryk på globustasten", "Gør ingenting")
  and step 3 ("Anonymitet og sikkerhed") must match the Danish macOS UI.
- TODO(copy): strings written by the backend and shown as they come: the
  DESK-31 speed reason (src-tauri/src/walkietalkey/speed.rs), "en telefon
  uden navn", and the notification titles (notify.rs).
- Handy's own components under Avanceret (microphone, log level, keyboard
  diagnostic, paste delays) keep Handy's Danish strings in `settings.*`.
- TODO(copy): `common.reset` ("Nulstil"), the screen reader name added to
  Handy's icon-only reset button.
