# Baggrunde

Stillbilleder af de flydende flader, med korn. Til slides, sociale medier, mails og alt der ikke kan køre `LiquidBackground`. 2560 × 1440 JPG.

- `morgengry.jpg`: platin, perle, sand og en smule rav med en blød lysstribe. Standard. Tekst i ink `#1b1a19` og `#3f3a35`.
- `flint.jpg`: kølig sølv i platin og perle. Til det tekniske. Tekst i ink `#1b1a19` og `#3f3a35`.
- `rav.jpg`: sand, rav og mokka. Til det varme og personlige. Tekst i ink `#1b1a19` og `#3f3a35`.
- `nat.jpg`: `night` med grafit- og bronzeglød. Til mørke slides. Tekst og logo i paper `#faf8f4`.
- `og-image.jpg`: 1200 × 630 delingsbillede til walkietalkey.com: lockuppen på Morgengry med "Tal. Slip. Indsæt."
