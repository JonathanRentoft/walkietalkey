# App-ikoner

- `app-icon-macos.png`: 1024 × 1024 macOS-ikon. Squircle med Morgengry (sølv og champagne) og mærket i ink `#1b1a19`, skygge indbygget. Til Mac-appen og Dock.
- `app-icon-macos-dark.png`: samme form på `night` med grafit- og bronzeglød og mærket i flydende metal. Til mørkt tema og som alternativ i App Store-materiale.
- `app-icon.png`: 1024 × 1024 fuldt felt uden hjørner og skygge. Til iOS og Android (systemet beskærer selv), web app manifest og profilbilleder.
- `favicon.svg`: mærket i ink `#1b1a19` på transparent bund, 128 × 128. Til browserfaner og bogmærker.
