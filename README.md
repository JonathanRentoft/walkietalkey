# WalkieTalkey

Free, open-source Danish dictation for Mac, Windows and your phone.

Hold `fn` on a Mac (or a key you choose on Windows), talk, let go, and the text appears where you are typing. Or hold the button in the phone app, talk, let go, and the text lands on the computer you are sitting at, on the clipboard with a small notification.

- Speech becomes text on your own computer, with a Danish speech model (Edda).
- Encrypted from phone to computer. The relay in between cannot read the audio.
- No accounts. No tracking.

WalkieTalkey is built on [Handy](https://github.com/cjpais/Handy) (MIT) and is licensed under Apache-2.0. See [NOTICE](NOTICE) for credits and [TRADEMARKS.md](TRADEMARKS.md) for the name and logo.

The full README (downloads, build instructions, privacy) is written in the v1 pull request. The system specification is in [docs/SPEC.md](docs/SPEC.md).
